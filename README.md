## 🚀 Usage Instructions

This repository is designed to provide AI agents with a diverse set of personas for engaging with the Shiba Inu community. To utilize a specific persona:

1.  **Clone the Repository**: `git clone https://github.com/ShibClaw/shibclaw-skill.git`
2.  **Load the Desired Skill**: Point your AI agent or system to the `SKILL.md` file within the respective persona's directory (e.g., `lucie-persona/SKILL.md` or `shytoshi-persona/SKILL.md`).
3.  **Engage with the Persona**: Interact with the loaded skill to generate responses, tweets, or content that aligns with the chosen persona's style and knowledge base.
